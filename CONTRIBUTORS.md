# Contributors

A special thank you to everyone who has contributed to **NETWATCH**!

## Core Maintainers

- **[@alwkala](https://github.com/alwkala)** — Architecture, Engineering & Core Design.

## Ways to Contribute

Contributions are welcome across all disciplines:
- 💻 **Code**: Core engine optimizations, low-level OS networking, UI components.
- 📖 **Documentation**: Guides, architecture refinement, translation.
- 🐛 **Bug Reports**: Finding edge cases in network adapter handling and ARP sweeps.
- 🎨 **Design**: UX feedback, icon design, and accessibility.
- 💡 **Ideas**: Suggesting local-first network diagnostic capabilities.

For instructions on how to get started, please see our [CONTRIBUTING.md](CONTRIBUTING.md) guide.
